# Learning Playground 🧑🏽‍💻

Welcome to my **Learning Playground**! This is where I practice coding concepts, work through exercises, and track my growth as I learn Python and eventually other languages.

## What's inside

| Folder | Contents |
| --- | --- |
| `python/coursework/examples/` | Example problems I worked through (`E` files) and in-class examples |
| `python/coursework/individual-assignments/` | Individual assignments (`IA` files), including related helper scripts |
| `python/coursework/labs/` | Extra lab problems I worked on outside class |
| `python/practice/` | Personal practice, experiments, and unfinished drafts |

The coursework folders contain work from the same Python class. Original filenames are preserved so I can match files to their problem and assignment numbers.

## Running a script

With Python 3 installed, run a script from the repository root, for example:

```bash
python3 "python/coursework/examples/E2.3.py"
```

Related assignment scripts stay in the same folder so local imports can resolve when running a script directly.

## My learning journey

This repository includes work in progress. Some files are incomplete or empty, and some contain duplicate versions. They are kept as part of my learning history; not every script is expected to run successfully.

My goals are to document my progress, stay consistent with practice, and keep experiments separate from larger projects. Larger projects, such as [SecAuthAPI](https://github.com/kkotufale/SecAuthAPI), have their own repositories.
